# Launcher Icons

The current icon files are placeholders.

## To add proper icons:

1. **Use Android Asset Studio:**
   - Go to: https://romannurik.github.io/AndroidAssetStudio/icons-launcher.html
   - Upload your icon image
   - Download the generated zip
   - Extract and replace the mipmap-* folders

2. **Or use Android Studio:**
   - Right-click `res` folder
   - New → Image Asset
   - Follow the wizard

3. **Manual method:**
   - Create PNG files in these sizes:
     - mdpi: 48x48px
     - hdpi: 72x72px
     - xhdpi: 96x96px
     - xxhdpi: 144x144px
     - xxxhdpi: 192x192px
   - Replace the placeholder files in each mipmap-* folder
